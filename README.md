# CitrusNet Paper Reproduction

CitrusNet reproduction project including:
- MobileViT baseline
- CitrusNet-V1 / V2 / V3
- SSL-BT pretraining
- classifier comparison
- HSV-based recovery monitoring
- TFLite export and Raspberry Pi deployment

## Status
In progress

## Repo structure
- `configs/` for training and model configs
- `src/citrusnet/` for code
- `tests/` for tests
- `scripts/` for utilities
- `data/` for local datasets only

## Notes
Raw datasets are kept local and are not committed to GitHub.
